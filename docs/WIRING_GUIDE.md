## 1. Справочник пинов Wemos D1 Mini

```
                  ┌───────┐
     RST ←──[RST] │       │[TX]──→ D1 (GPIO1, Serial TX)
      A0 ←──[ADC] │       │[RX]──→ D2 (GPIO3, Serial RX)
       D0 ←──[D0] │ WEMOS │[D1]──→ D1 (GPIO5, I2C SCL)
       D3 ←──[D3] │ D1    │[D2]──→ D2 (GPIO4, I2C SDA)
       D4 ←──[D4] │ Mini  │[D5]──→ D5 (GPIO14, SPI SCK)
     3V3 ←──[3V3] │       │[D6]──→ D6 (GPIO12, SPI MISO)
       G ←──[GND] │       │[D7]──→ D7 (GPIO13, SPI MOSI)
       5V ←──[5V] │       │[D8]──→ D8 (GPIO15, SPI CSN)
                  └───────┘
```

### Назначение пинов в проекте

| Пин | GPIO | Функция | Вариант | Примечание |
|-----|------|---------|---------|------------|
| D0 | GPIO16 | **BUZZER_PIN** | Клиент | Активный зуммер. Нет PWM/tone! |
| D1 | GPIO5 | **I2C_SCL** | Сервер | OLED дисплей SCL |
| D2 | GPIO4 | **I2C_SDA** | Сервер | OLED дисплей SDA |
| D3 | GPIO0 | **LED_PIN** | Клиент | Сигнальный LED. **Должен быть HIGH на старте!** |
| D4 | GPIO2 | **CE_PIN** / LED2 | NRF24 / WiFi | Chip Enable. Встроенный LED на Wemos. В WiFi сервере — LED2 |
| D5 | GPIO14 | **SPI SCK** | NRF24 | Тактовый сигнал SPI |
| D6 | GPIO12 | **SPI MISO** | NRF24 | Данные SPI (вход) |
| D7 | GPIO13 | **SPI MOSI** | NRF24 | Данные SPI (выход) |
| D8 | GPIO15 | **CSN_PIN** | NRF24 | Chip Select SPI |
| A0 | ADC | **MQ2_PIN** | Клиент | Аналоговый вход MQ-2 (0–3.3V) |
| TX | GPIO1 | Serial | Отладка | Не занят |
| RX | GPIO3 | Serial | Отладка | Не занят |
| 5V | — | Питание | Все | Вход 5V от USB или внешнего источника |
| 3V3 | — | 3.3V | Все | Выход регулятора, макс. ~400 мА |
| G | — | GND | Все | Общий |

### ⚠️ Важные замечания по пинам

- **D3 (GPIO0)** подключён к LED на клиенте. При старте Wemos этот пин должен быть HIGH (LED выключен), иначе плата перейдёт в режим UART Download (прошивка). Код устанавливает `digitalWrite(LED_PIN, LOW)` **после** `pinMode(...)`, что не влияет на boot — на момент старта пин в Hi-Z, внутренняя подтяжка держит HIGH.
- **D0 (GPIO16)** не поддерживает `analogWrite()`/`tone()` — только `digitalWrite()`.
- **D8 (GPIO15)** должен быть LOW на старте — резистор 10kΩ к GND на SPI-шине (обычно встроен в Wemos, но убедитесь).
- **TX/RX** заняты USB-Serial (CH340). Не используйте для других целей.

## 2. Сервер

### 2.1. WiFi сервер (только OLED + LED)

```
Wemos D1 Mini (Сервер WiFi)
┌───────────────────────────────────────────────────┐
│                                                   │
│  ──── SSD1306 OLED (I2C) ────                     │
│  D1 ─────── SCL                                   │
│  D2 ─────── SDA                                   │
│  3V3 ────── VCC                                   │
│  GND ────── GND                                   │
│                                                   │
│  ──── Светодиоды (активный HIGH) ────             │
│  D3 ── 220Ω ── ┤LED1├ ── GND                      │
│  D5 ── 220Ω ── ┤LED2├ ── GND                      │
│  D6 ── 220Ω ── ┤LED3├ ── GND                      │
│  D7 ── 220Ω ── ┤LED4├ ── GND                      │
│                                                   │
│  ──── Питание ────                                │
│  5V ─────── USB / External 5V                     │
│  GND ────── Общий провод                          │
└───────────────────────────────────────────────────┘
```

**Светодиоды:** 4 шт, аноды к GPIO через резистор 220Ω, катоды к GND.  
Активный уровень: HIGH (pin = 3.3V → LED горит).  
Пины: D3, D5, D6, D7 (совпадают с кодом прошивки).

### 2.2. Сервер с NRF24 (OLED + LED + NRF24)

```
Wemos D1 Mini (Сервер NRF24)
┌───────────────────────────────────────────────────┐
│                                                   │
│  ──── OLED (SSD1306) ────                         │
│  D1 ─────── SCL                                   │
│  D2 ─────── SDA                                   │
│  3V3 ────── VCC                                   │
│  GND ────── GND                                   │
│                                                   │
│  ──── NRF24L01+PA+LNA ────                        │
│  D4 ─────── CE                                    │
│  D8 ─────── CSN                                   │
│  D5 ─────── SCK                                   │
│  D7 ─────── MOSI                                  │
│  D6 ─────── MISO                                  │
│  3V3 ────── VCC  (через 10µF конденсатор!)        │
│  GND ────── GND                                   │
│                                                   │
│  ──── Светодиоды (активный HIGH) ────             │
│  D3 ── 220Ω ── ┤LED1├ ── GND                      │
│  RX ── 220Ω ── ┤LED2├ ── GND                      │
│  TX ── 220Ω ── ┤LED3├ ── GND                      │
│  D0 ── 220Ω ── ┤LED4├ ── GND                      │
│                                                   │
│  ──── Питание ────                                │
│  5V ─────── USB / External 5V                     │
│  GND ────── Общий провод                          │
└───────────────────────────────────────────────────┘
```

**Светодиоды:** аноды к GPIO через 220Ω, катоды к GND, активный HIGH.  
**⚠️ Важно:** Пины D5/D6/D7 заняты SPI (NRF24), поэтому LED подключены к D3, RX, TX, D0 — они не конфликтуют с NRF24.

> **Известная проблема в коде:** `server_firmware_nrf24.ino` (строка 341) задаёт LED пины как `{D3, D5, D6, D7}`, но D5=SCK, D6=MISO, D7=MOSI — пины SPI модуля NRF24. После `pinMode(D5, OUTPUT)` аппаратный SPI отключается от этих пинов, и связь по NRF24 перестаёт работать.  
> **Решение:** Используйте схему подключения LED к D3, RX, TX, D0 (как показано выше) и замените в коде:
> ```cpp
> int ledPins[MAX_CLIENTS] = { D3, RX, TX, D0 };
> pinMode(D3, OUTPUT); pinMode(RX, OUTPUT); pinMode(TX, OUTPUT); pinMode(D0, OUTPUT);
> ```

### Схема подключения OLED (SSD1306 128×64 I2C)

```
OLED SSD1306     Wemos D1 Mini
┌─────────┐     ┌─────────────┐
│ SCL     │─────│ D1  (GPIO5) │
│ SDA     │─────│ D2  (GPIO4) │
│ VCC     │─────│ 3V3         │
│ GND     │─────│ GND         │
└─────────┘     └─────────────┘
```

- Адрес I2C: **0x3C** (почти все дисплеи)
- Если дисплей не работает — проверьте адрес I2C сканером
- Подтягивающие резисторы SDA/SCL (4.7kΩ) обычно встроены в модуль OLED

### Схема подключения светодиодов (сервер)

**WiFi сервер (LED на D3, D5, D6, D7):**
```
Wemos D3 ─── 220Ω ── ┤LED1├ ──── GND
Wemos D5 ─── 220Ω ── ┤LED2├ ──── GND
Wemos D6 ─── 220Ω ── ┤LED3├ ──── GND
Wemos D7 ─── 220Ω ── ┤LED4├ ──── GND
```

**NRF24 сервер (LED на D3, RX, TX, D0 — SPI пины заняты):**
```
Wemos D3 ─── 220Ω ── ┤LED1├ ──── GND
Wemos RX ─── 220Ω ── ┤LED2├ ──── GND
Wemos TX ─── 220Ω ── ┤LED3├ ──── GND
Wemos D0 ─── 220Ω ── ┤LED4├ ──── GND
```

> **⚠️ В текущей прошивке `server_firmware_nrf24.ino` LED ошибочно выведены на D5/D6/D7 (конфликт с SPI).** Используйте схему выше и замените код — см. примечание в разделе [2.2](#22-сервер-с-nrf24-oled--led--nrf24).

**Полярность:** анод(+) к Wemos, катод(−) к GND.  
**Активный уровень:** HIGH (3.3V на пине → LED горит).  
**Расчёт резистора:** `R = (3.3 - 2) / 0.01 = 130Ω`. 220Ω даёт ~6 мА — достаточно.

### Схема подключения LED (клиент)

```
Wemos D3 (GPIO0) ──── 220Ω ── ┤LED├ ──── GND
                               Анод(+) к D3
                               Катод(-) к GND
```

- LED горит при HIGH на D3
- Мигает 200мс при обнаружении газа

### Схема подключения активного зуммера

```
Wemos D0 (GPIO16) ──── ┤BUZZER(Active)├ ──── GND
                          (+)      (-)
```

- **Полярность важна!** Плюс зуммера к D0, минус к GND
- D0 не поддерживает PWM/tone — зуммер включается/выключается `digitalWrite()`
- Частота определяется программным переключением (100мс)

## 4. Делитель напряжения для MQ-2

### Проблема

MQ-2 выдает **0–5V** на аналоговом выходе. Wemos D1 mini A0 принимает **0–3.3V**.  
Прямое подключение **сожжёт** вход A0!

### Решение: резистивный делитель 1:2

```
MQ-2 Sensor              Делитель              Wemos D1 Mini
┌──────────┐                                 ┌─────────┐
│          │    OUT                          │         │
│ A0  ─────┼───────────── 10kΩ ──┬───────────┼── A0    │
│          │                     │           │         │
│ 5V  ─────┼──                   │      3.3V │         │
│          │                    ┌┴┐     max  │         │
│ GND ─────┼──                 20kΩ          │         │
│          │                    └┬┘          │         │
│          │                     │           │         │
│          │                   GND┐          │         │
└──────────┘                                 └─────────┘
```

**Формула:** `Vout = Vin × 20k / (10k + 20k) = Vin × 2/3`  
- При 5V: Vout = 5 × 2/3 = **3.33V** — в допуск
- При 4.5V (минимум питания MQ-2): Vout = 4.5 × 2/3 = **3.0V** — в допуск

### Альтернативные варианты делителя

| R1 | R2 | Коэффициент | Vout max (при 5V) | В допуск? |
|----|----|-------------|-------------------|-----------|
| 10kΩ | 20kΩ | 0.667× | 3.33V | ✅ Да |
| 10kΩ | 10kΩ | 0.500× | 2.50V | ✅ Да (запас) |
| 20kΩ | 10kΩ | 0.333× | 1.67V | ✅ Да (большой запас, меньше разрешение) |
| 10kΩ | 15kΩ | 0.600× | 3.00V | ✅ Да |
| 10kΩ | 22kΩ | 0.688× | 3.44V | ⚠️ На грани (3.3V + погрешность) |

**Рекомендуемый:** 10kΩ + 20kΩ (стандартные номиналы E12/E24).

## 5. Питание

### 5.1. От USB (тестирование)

```
USB 5V ───── USB-порт Wemos D1 mini
               │
         ┌─────┴─────┐
         │ 5V (USB)  │
         └─────┬─────┘
               │
         ┌─────┴─────┐
         │ Wemos 5V  │
         │ pin (Vin) │
         └─────┬─────┘
               │
         ┌─────┴─────┐
         │ MQ-2 VCC  │
         └───────────┘
```

- **Внимание:** USB даёт 5V для MQ-2. Выход 3V3 на Wemos — только для NRF24/OLED
- Ток по USB: до 500 мА (Wemos ~80 мА + MQ-2 ~170 мА = ~250 мА — достаточно)

### 5.2. От внешнего источника 5V

```
External PSU 5V (+) ──┬── Wemos 5V pin (Vin)
                      │
                      └── MQ-2 VCC

External PSU GND ─────┬─ Wemos GND
                      └── MQ-2 GND
```

- Любой стабилизированный источник 5V, >300 мА
- Power Bank 5V — идеально

### 5.3. От литиевого аккумулятора 18650

Одна 18650 (3.0–4.2V) не подходит — нужен повышающий преобразователь.

```
18650 (+) ──── IN+ MT3608 (Boost) OUT+ ──┬── Wemos 5V pin (Vin)
3.0-4.2V                                 │
                                         └── MQ-2 VCC
                                  
18650 (-) ──── IN- MT3608 (Boost) OUT- ──── GND (общий)
```

**Настройка MT3608:**
1. Подключите 18650 к входу MT3608
2. Мультиметром настройте потенциометр на 5.0V на выходе
3. Подключите Wemos и MQ-2

**Время работы:** ~4–5 часов на одной банке 2000–3000 mAh (MQ-2 потребляет ~170 мА на нагреватель).

### 5.4. Сводная таблица питания

| Источник | Напряжение | MQ-2 | Wemos | NRF24 | Время работы* |
|----------|-----------|------|-------|-------|--------------|
| USB (компьютер) | 5V | ✅ | ✅ | ✅ | ∞ |
| USB Power Bank | 5V | ✅ | ✅ | ✅ | 4–6 ч |
| 18650 + MT3608 | → 5V | ✅ | ✅ | ✅ | 4–5 ч |
| 2×18650 + LM7805 | 7.4V → 5V | ✅ | ✅ | ✅ | 8–10 ч |
| 18650 напрямую | 3.0–4.2V | ❌ | ❌ | — | — |
| 3.3V от Wemos | 3.3V | ❌ | — | ✅ | — |

\* На одной банке 2000–3000 mAh, клиент с NRF24

### ❌ Что НЕЛЬЗЯ делать

1. **Питать MQ-2 от 3.3V пина Wemos** — нагреватель не нагреется до рабочей температуры
2. **Питать Wemos от одной 18650 без boost** — AMS1117-3.3V требует вход >4.5V
3. **Подключать MQ-2 напрямую к A0** — 5V сожжёт ADC вход Wemos
4. **Подавать 5V на 3.3V пин Wemos** — сожжёт регулятор
5. **Подавать >9V на Vin** —AMS1117 сгорит (макс. 12V, но >9V опасно)

## 7. Проверка перед включением

### Чек-лист перед подачей питания

- [ ] Нет ли замыканий между 5V и GND? (проверьте мультиметром)
- [ ] Нет ли замыканий между 3V3 и GND?
- [ ] Делитель MQ-2: 10kΩ + 20kΩ между A0 датчика и A0 Wemos?
- [ ] MQ-2 VCC подключён к 5V, **а не к 3V3**?
- [ ] NRF24 VCC к 3V3 (не к 5V!) с конденсатором 10µF?
- [ ] OLED VCC к 3V3 (не к 5V)?
- [ ] LED подключен через резистор 220Ω?
- [ ] Зуммер: плюс к D0, минус к GND?
- [ ] **D3 (GPIO0)** — LED клиента? Убедитесь, что контакт не притянут к GND при старте (чтобы не войти в flash mode)
- [ ] **D8 (GPIO15)** — есть подтяжка к GND? (обычно встроена в Wemos, но при подключении NRF24 проверьте)

### Если что-то не работает

| Симптом | Причина | Решение |
|---------|---------|---------|
| Нет питания | Замыкание | Проверьте мультиметром, убедитесь в подключении GND |
| Wemos не запускает скетч | D3 (GPIO0) был LOW при старте — режим UART Download | Подтяните D3 к 3.3V (10kΩ), отключите LED, перезагрузите |
| Wemos в цикле перезагрузки (boot loop) | Конфликт пинов или недостаток питания | Проверьте конденсатор 10µF у NRF24, стабильность 5V |
| OLED пустой | Неправильный адрес I2C | Запустите I2C сканер |
| NRF24 не инициализируется | Провода или конденсатор | Проверьте все соединения, добавьте 10µF |
| MQ-2 показывает 0 | Не прогрелся | Ждите 1 мин (полный прогрев 5–10 мин) |
| MQ-2 показывает 1023 всегда | Делитель не работает | Проверьте 10kΩ + 20kΩ |
| MQ-2 показывает странно | Нет 5V на нагревателе | Подключите VCC к 5V, не к 3V3 |
| LPG PPM = 0 после калибровки | Калибровка на сбойном R0 | Выполните `calibrate` через Serial после прогрева |
| Buzzer не пищит | Перепутана полярность | Проверьте `(+)` к D0, `(-)` к GND |
| Buzzer пищит постоянно | Активный зуммер (с генератором) | Нормально при gasDetected |
