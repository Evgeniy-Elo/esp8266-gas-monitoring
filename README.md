# ESP8266 Gas Monitoring System

Распределённая система мониторинга концентрации газа (MQ-2) на базе ESP8266 Wemos D1 mini.

## 📋 Архитектура системы

### Оборудование

**Сервер (1 устройство):**
- Wemos D1 mini (ESP8266)
- SSD1306 OLED дисплей 128x64 (I2C)
- 4 светодиода (D3, D4, D5, D6)
- WiFi точка доступа (AP)

**Клиенты (4 устройства, ID: 1-4):**
- Wemos D1 mini (ESP8266)
- Датчик MQ-2
- 1 светодиод (D8)
- Активный пьезодинамик (D7)
- WiFi клиент (подключается к AP серверу)

## 🔧 Конфигурация

### WiFi параметры (`config.h`)
```cpp
#define WIFI_SSID "GAS_MONITOR_AP"
#define WIFI_PASSWORD "12345678"
#define SERVER_IP_ADDR IPAddress(192, 168, 4, 1)
#define SERVER_PORT 8888
```

### Пороги срабатывания
```cpp
#define GAS_THRESHOLD 300   // Пороговое значение для датчика MQ-2
```

### Пины подключения

**Клиент:**
- A0 - аналоговый вход MQ-2
- D7 - пьезодинамик
- D8 - светодиод

**Сервер:**
- D1 (GPIO5) - SCL (I2C дисплей)
- D2 (GPIO4) - SDA (I2C дисплей)
- D3 (GPIO0) - LED device 1
- D4 (GPIO2) - LED device 2
- D5 (GPIO14) - LED device 3
- D6 (GPIO12) - LED device 4

## 📡 Протокол передачи данных

Простой текстовый протокол через TCP сокет:

**Регистрация клиента:**
```
REG:1\n
```

**Отправка данных (в реальном времени):**
```
DATA:1:456\n
```
Формат: `DATA:device_id:gas_level`

## 🚀 Поведение системы

### Клиент:
1. Подключается к WiFi AP серверу
2. Отправляет регистрационное сообщение
3. Непрерывно читает датчик MQ-2 (каждые 100 мс)
4. Отправляет данные на сервер (каждые 500 мс)
5. **При обнаружении газа (уровень > 300):**
   - Включает звук (пьезодинамик на частоте 1000 Гц)
   - Быстро мигает светодиодом (период 200 мс)

### Сервер:
1. Создаёт WiFi точку доступа
2. Слушает подключения клиентов на порту 8888
3. При подключении клиента зажигает соответствующий светодиод
4. Отображает на дисплее:
   - Уровень концентрации газа от каждого устройства
   - Статус подключения
   - Активные оповещения
5. **При обнаружении газа от клиента:**
   - Начинает мигать соответствующий светодиод (период 200 мс)
   - Обновляет информацию на дисплее

## 📦 Установка зависимостей

### Arduino IDE:
1. Добавить поддержку ESP8266 в Board Manager
2. Установить библиотеки:
   - `Adafruit SSD1306`
   - `Adafruit GFX Library`

### PlatformIO (рекомендуется):
```ini
[env:wemos_d1_mini]
platform = espressif8266
board = d1_mini
framework = arduino

lib_deps =
    adafruit/Adafruit SSD1306 @ ^2.5.0
    adafruit/Adafruit GFX Library @ ^1.11.0
```

## 💾 Загрузка прошивок

### Для сервера:
1. Откройте `server_firmware/server_firmware.ino`
2. Выберите плату: Wemos D1 mini
3. Загрузите на сервер

### Для каждого клиента:
1. Откройте `client_firmware/client_firmware.ino`
2. **Измените `DEVICE_ID` на номер устройства (1-4):**
   ```cpp
   #define DEVICE_ID 1  // Измените на 1, 2, 3 или 4
   ```
3. Загрузите на клиент
4. Повторите для каждого клиента с соответствующим ID

## 🐛 Возможные проблемы

### Клиент не подключается к серверу:
1. Проверьте SSID и пароль WiFi в `config.h`
2. Убедитесь, что сервер включен и активен
3. Проверьте IP адрес сервера (должен быть 192.168.4.1)

### Дисплей не показывает информацию:
1. Проверьте подключение I2C (SDA на D2, SCL на D1)
2. Убедитесь, что адрес дисплея 0x3C
3. Попробуйте I2C сканер для диагностики

### Датчик MQ-2 показывает странные значения:
1. Дайте датчику время на прогрев (5-10 минут)
2. Проверьте аналоговое подключение на A0
3. Убедитесь в стабильном питании
