# ESP8266 Gas Monitoring System

Распределённая система мониторинга концентрации газа (MQ-2) на базе ESP8266 Wemos D1 mini.

## 📋 Архитектура системы

### Два варианта реализации:

**1. WiFi TCP/IP версия** (базовая)
- Сервер создаёт WiFi точку доступа
- Клиенты подключаются как WiFi станции
- Связь через TCP сокеты

**2. NRF24L01+PA+LNA версия** (расширенная)
- Беспроводная связь 2.4 GHz
- Дальность до 1000м (с антенной)
- Меньше энергопотребление

---

## 🎯 Выбор версии

| Критерий | WiFi | NRF24 |
|----------|------|-------|
| Дальность | 20-50м | 200-1000м |
| Помехи | Может быть помеха от WiFi | Независимая частота |
| Сложность | Простая | Средняя |
| Цена | Дешевле | Дороже (модули) |
| Энергопотребление | Выше | Ниже |
| Рекомендуется для | Дома, офис | Склад, производство |

## 📦 Оборудование

### Сервер (1 устройство):
- **Wemos D1 mini** (ESP8266)
- **SSD1306 OLED дисплей** 128x64 (I2C)
- **4 светодиода** (разные цвета по желанию)
- **Для NRF24**: NRF24L01+PA+LNA модуль

### Клиенты (4 устройства, ID: 1-4):
- **Wemos D1 mini** (ESP8266)
- **Датчик MQ-2** (аналоговый)
- **1 светодиод** (индикация локального состояния)
- **Активный пьезодинамик** (сирена)
- **Для NRF24**: NRF24L01+PA+LNA модуль

## ⚡ Конфигурация

### WiFi параметры (`config.h`):
```cpp
#define WIFI_SSID "GAS_MONITOR_AP"
#define WIFI_PASSWORD "12345678"
#define SERVER_IP_ADDR IPAddress(192, 168, 4, 1)
#define SERVER_PORT 8888
```

### Общие параметры:
```cpp
#define GAS_THRESHOLD 300            // Порог для MQ-2 (0-1023)
#define MAX_CLIENTS 4                // Максимум устройств
#define CLIENT_TIMEOUT 5000          // Таймаут отключения клиента (мс)
#define CONNECTION_RETRY_INTERVAL 5000 // Переподключение каждые 5с
```

### Таймеры:
```cpp
#define SENSOR_READ_INTERVAL 100     // Чтение датчика каждые 100мс
#define DATA_SEND_INTERVAL 500       // Отправка данных каждые 500мс
#define LED_BLINK_INTERVAL 200       // Мигание LED при alert каждые 200мс
#define BUZZER_TONE_DURATION 100     // Длительность сигнала зуммера (мс)
```

### NRF24:
```cpp
#define NRF24_CHANNEL 76             // 2.476 GHz
#define NRF24_DATA_RATE 250          // 250 kbps
#define NRF24_PA_LEVEL 3             // 0=min, 3=max
#define CE_PIN D4
#define CSN_PIN D8
```

## 🚀 Быстрый старт - WiFi версия

### Шаг 1: Сервер
1. Откройте `server_firmware/server_firmware.ino`
2. Загрузите на сервер (Wemos D1 mini)
3. Откройте Serial Monitor (115200 baud)
4. Должна появиться информация о WiFi AP

### Шаг 2: Клиенты (повторить 4 раза)
1. Откройте `client_firmware/client_firmware.ino`
2. **Измените DEVICE_ID:**
   ```cpp
   #define DEVICE_ID 1  // Измените на 1, 2, 3, 4
   ```
3. Загрузите на клиент
4. Повторите для остальных (ID 2, 3, 4)

### Результат:
- На экране сервера появятся 4 секции с показаниями
- LED будут гореть/мигать при подключении/alert

   - `client_firmware_nrf24/`
4. Остальное как в WiFi версии

## 📱 Дисплей сервера

Экран разделён на **4 части** (2x2 сетка):

### Нормальное состояние:
```
┌─────────────┬─────────────┐
│  D1         │  D2         │
│             │             │
│   245       │   198       │
│             │             │
├─────────────┼─────────────┤
│  D3         │  D4         │
│             │             │
│   267       │   212       │
│             │             │
└─────────────┴─────────────┘
```

### С обнаруженным газом (инверсия):
```
┌─────────────┬─────────────┐
│  D1         │█████D2██████│
│             │█   310   █  │  ← Мигает инверсия
├─────────────┼─────────────┤
│  D3         │  D4         │
│             │             │
│   267       │   212       │
└─────────────┴─────────────┘
```

- **D1-D4**: номера устройств
- **Большие цифры**: текущий уровень газа
- **--**: устройство отключено
- **Инверсия**: обнаружен газ (мигание 200мс)

## ⚠️ Частые проблемы

### WiFi версия

**Клиент не подключается:**
- Проверьте SSID и пароль в config.h
- Убедитесь, что сервер включен
- Попробуйте переподключить питание

**Дисплей не показывает:**
- Проверьте подключение I2C (D1=SCL, D2=SDA)
- Адрес дисплея: 0x3C
- Используйте I2C сканер для диагностики

**Датчик MQ-2 показывает странно:**
- Дайте датчику 5-10 минут на прогрев
- Проверьте аналоговое подключение (A0)
- Проверьте питание 3.3V

### NRF24 версия

📖 См. раздел "Возможные проблемы" в [`docs/NRF24_SETUP.md`](docs/NRF24_SETUP.md)

**Кратко:**
- NRF24 не инициализируется → проверить провода и конденсатор
- Нет связи → проверить адрес "GASMO" и канал 76
- Нестабильно → добавить конденсатор 100nF

## 📊 Протокол связи

### WiFi TCP:
```
Регистрация:   REG:1\n
Отправка:      DATA:1:245\n
Формат:        DATA:device_id:gas_level
```

### NRF24 (бинарный):
```cpp
struct {
  uint8_t  deviceId;     // 1-4
  uint16_t gasLevel;     // 0-1023
  uint32_t timestamp;    // мс
}
```

## 🔊 Поведение при обнаружении газа

- 🔴 Светодиод мигает (200мс период)
- 🔔 Активный зуммер прерывисто пищит (100мс вкл/выкл)

- 🟢 LED соответствующего устройства мигает (200мс период)
- 📱 На дисплее инверсия фона в соответствующей секции
- 📊 Статус "ALERTS: N" если есть оповещения

## 🔐 Безопасность

Текущая версия не использует шифрование.

Для добавления:
1. Использовать другой адрес вместо "GASMO"
2. Добавить XOR или простое шифрование
3. Добавить CRC проверку пакетов
